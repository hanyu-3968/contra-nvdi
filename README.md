# 魂斗罗 Web 版 (Contra Web)

经典 FC 游戏《魂斗罗》的网页复刻版，使用 Vue 3 + HTML5 Canvas 实现，还原 8-bit 像素画风与经典音效，支持 PC 键盘与手机触屏双端游玩。

## 特性

- **三关完整流程**：丛林基地 → 沙漠战场 → 水下深渊，每关有独立主题、地形与敌人
- **纯代码生成素材**：所有精灵图、瓦片、背景均由 Canvas 像素绘制函数生成，无外部图片依赖
- **程序化音效**：基于 Web Audio API 的 OscillatorNode + 噪声合成，还原 NES 风格射击/爆炸/BGM 音效，无外部音频文件
- **双端适配**：PC 端键盘操控，移动端虚拟方向键 + 动作按钮，自适应屏幕缩放
- **多武器系统**：普通弹(N)、机关枪(M)、散弹(S)、激光(L)、火球(F)，关卡中拾取道具切换
- **混合移动机制**：第三关水下场景中，平台区域为标准跳跃，深水区自动切换为八方向游泳物理（浮力/水阻力/气泡粒子）
- **关卡过渡**：通关后保留分数、生命与当前武器进入下一关

## 技术栈

| 层面 | 技术 |
|------|------|
| 前端框架 | Vue 3.4 (Composition API) |
| 构建工具 | Vite 5.2 |
| 渲染引擎 | HTML5 Canvas 2D（禁用图像平滑，保持像素感） |
| 音频系统 | Web Audio API（OscillatorNode / 噪声缓冲） |
| 物理碰撞 | AABB（Axis-Aligned Bounding Box）检测 |

```
src/

├── main.js                     # 应用入口
├── components/
│   ├── HUD.vue                 # 顶栏 HUD（分数/生命/武器/关卡/音效开关）

│   └── Overlay.vue             # 菜单/游戏结束/胜利覆盖层

    ├── engine/
    │   ├── Game.js             # 游戏主循环：状态管理、实体更新、碰撞、渲染调度
    │   ├── Level.js            # 关卡管理：瓦片地图、碰撞查询、背景与水域渲染
    │   ├── Camera.js           # 摄像机：水平跟随玩家
    │   ├── Input.js            # 输入系统：键盘 + 触摸统一抽象
    │   ├── Audio.js            # 音效系统：程序化生成 8-bit 音效与 BGM
    │   └── Sprites.js          # 像素绘制函数库（玩家、敌人、瓦片、背景、特效）
    ├── entities/
    │   ├── Player.js           # 玩家：移动、跳跃、蹲伏、游泳、八方向瞄准、射击
    │   ├── Enemy.js            # 敌人：9 种类型 AI（步兵/炮台/机甲/青蛙兵/水雷/水母/鱼雷/章鱼/深海机甲）
    │   ├── Bullet.js           # 子弹：玩家与敌人子弹，多种类型与弹道
    │   ├── PowerUp.js          # 道具：武器升级拾取
    │   └── Explosion.js        # 爆炸特效
    └── levels/
        ├── level1.js           # 第一关 - 丛林（瓦片地图 + 敌人 + 道具配置）
        ├── level2.js           # 第二关 - 沙漠
        └── level3.js           # 第三关 - 水下（含 waterZones 深水区定义）
```

## 快速开始

### 环境要求

- Node.js >= 16
- npm >= 8

### 安装与运行

```bash
# 安装依赖
npm install

# 启动开发服务器 (默认 http://localhost:5173)
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 操作说明

### PC 键盘

| 按键 | 功能 |
|------|------|
| ← → / A D | 左右移动 |
| ↑ / W | 向上瞄准 |
| ↓ / S | 蹲下 / 水中下潜 |
| Z / 空格 | 跳跃 / 水中上浮 |
| X / J | 射击 |
| Enter | 暂停 / 继续 |

### 手机触屏

- 左下角虚拟方向键：移动 / 瞄准 / 蹲下
- 右下角动作按钮：跳跃 / 射击
- 顶部暂停按钮

### 水下关卡操作

进入深水区后自动切换为游泳模式：
- **左右键**：水平游动
- **跳跃键（Z/空格）**：上浮
- **下键（↓/S）**：下潜
- **组合方向**：八方向瞄准与移动（如 ↑+→ 为右上斜游）
- 无操作时受浮力影响缓慢上浮

## 调试功能

通过 URL 查询参数快速测试（不在游戏界面中暴露）：

```bash
# 直接进入第二关
# http://localhost:5173/?level=2

# 直接进入第三关 + 无敌模式
# http://localhost:5173/?level=3&god=1
```

| 参数 | 说明 |
|------|------|
| `?level=N` | N=1/2/3，跳过菜单直接进入指定关卡 |
| `?god=1` | 无敌模式，玩家不受伤害，复活后仍保持 |

浏览器控制台也可通过 `window.__contra` 访问游戏实例进行调试。

## 技术要点

- **固定时间步长游戏循环**：60 FPS 逻辑更新，`requestAnimationFrame` 驱动渲染
- **实体池化**：子弹与爆炸特效复用对象，减少 GC 压力
- **视口裁剪渲染**：仅绘制摄像机可见范围内的瓦片，支持超长关卡（200+ 瓦片列）
- **像素精确绘制**：自定义 `px()` 函数逐块绘制，`image-rendering: pixelated` 确保缩放后像素清晰
- **输入边沿检测**：`jumpPressed` / `shootPressed` 区分按住与按下，支持跳跃和单发射击
- **状态机管理**：menu / playing / paused / levelclear / gameover / victory 六种状态切换
